Supernote plugin · design review · revision 4 · 5 Nov 2026

Stencil

Shipped as Stencil 1.0.0 on 6 Nov 2026; this page is the design record.

A Supernote plugin that places clean or hand-drawn diagram shapes on the page with the pen. Revision 3 folds in six rounds of device spikes on a Manta: shapes are sized at insert time by tap or drag, never scaled afterwards, and every shape carries a recipe so it can be redrawn into a new box.

Panel, then strip

Choosing happens in a panel on the left of a transparent layer. Placing happens from a strip along the top, with the whole page free below it. The tabs and glyph chips work in both and drive the shape sheet further down.

Hand-drawn look

The reference is Excalidraw's lowest sloppiness: a shape a product designer would draw by hand, not a shaky one. The renderer below is the one the plugin runs. It splits each outline at corners into pen strokes, gives each stroke one gentle bow, a width profile over its length and a little overshoot where strokes meet. On the device the width profile becomes pressure on pen type 16: the stroke thickness is set to the profile's peak and each sample's pressure comes from the measured curve, 400 for a third of full width up to 1600 for full width. The constants were tuned here and confirmed on the Manta.

Device findings

Six rounds of a spike plugin on a Manta, 4 and 5 November 2026, cross-checked by rendering the spike notes locally. Full table in the project README.

  • Strokes need only points and pressures. Writing contours or recognition data breaks lasso hit-testing, so the renderer never writes it.
  • Pen 16 follows pressure, pen 10 does not. Rendered width grows from pressure 400 to about 1600 and is flat above. Pen 16 can only thin a stroke below its thickness. Pen 15 is direction dependent, pen 11 is the marker.
  • Width unit. Element thickness and geometry pen width share one unit: 0.5 mm is about 600, 1.0 mm about 1200. Values below 100 draw hairlines.
  • No gaps inside a stroke. The pen-up flag is ignored and zero pressure is a hairline. Dashes and hatch are separate strokes.
  • Geometry stretches, strokes do not, and both degrade: the native lasso scales line width with the shape, and bows and overshoots drawn for one size distort at another. Hence size at insert and redraw instead of scale.
  • Undo. Geometry inserted with the geometry API keeps undo; page-element inserts of strokes do not.
  • Lasso after insert works when the plugin view is closed first. Geometry has a flag that does it on insert.
  • Placement by pen works through ordinary React Native touch handling on a transparent root; the page stays visible. A solid rubber band is needed because partial refresh drops dashes.
  • Recipes round-trip. A JSON tag in the element's user data survives the lasso and drives redraw. Geometry inserted via the geometry API cannot carry one.
  • Delete only inside the lasso. Deleting page elements that are not in the current lasso closes the note (7 Nov 2026). Redrawing part of a shape therefore lassoes the whole shape before deleting it.

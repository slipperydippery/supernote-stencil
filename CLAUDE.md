# Stencil — Supernote plugin

React Native plugin for Supernote (Chauvet firmware) built on `sn-plugin-lib`. Pure JavaScript: no native modules, no Android SDK. The bundle runs inside the host's React Native container on the device.

## Commands

- `npm ci` — install (lockfile is authoritative).
- `npm run typecheck` — `tsc --noEmit`.
- `npm test` — Jest, `react-native` preset.
- `./buildPlugin.sh` — Metro bundle + zip → `build/outputs/stencil.snplg`. No device needed.
- Install: copy the `.snplg` to the device's `MyStyle` folder (USB MTP; the volume is named "Supernote Nomad" even for a Manta), then Settings → Apps → Plugins → Add Plugin.

Worktree setup: `npm ci`

Pre-push gate: `npm run typecheck && npm test && ./buildPlugin.sh`

## Conventions

- Branches `<type>/GH-<n>-<intent>`; commits `<type>(<scope>): <summary> (GH-<n>)`, scope = module (`shapes`, `render`, `device`, `ui`, `build`).
- `src/shapes` and `src/render` never import `sn-plugin-lib` or `react-native` (they run in Jest and in the icon script).
- Only `src/device` talks to the SDK.
- No SVG at runtime: shape and glyph icons are committed PNGs under `assets/`, generated by `npm run icons`.
- Hand-drawn look = a confident illustrator (think product designer): one smooth pen stroke per run between sharp corners, however long. Never split a smooth run into pieces; each piece gets its own bow and width profile, and the seams read as hesitant multiple passes.

## Device facts that bind the code

The measured findings live in `README.md` ("Results" table). The ones that shape every change:

- Strokes need only points and pressures. Never write `contoursSrc`, `angles`, `markPenDirection`, `recognPoints`, `flagDraw`.
- Width unit is the firmware's internal unit (0.5 mm ≈ 600); always write a non-integer value.
- Pen 16 follows pressure (400 → thin, 1600 → full width), pen 10 does not. Fills, dashes and clean outlines use pen 10.
- Insert through `PluginCommAPI.insertPageElements`; never `saveCurrentNote` + `reloadFile` around an insert.
- Native lasso scaling degrades shapes; shapes are sized at insert and regenerated from the recipe in `Element.userData`.
- Close the plugin view before `lassoElements`, with no timer in between: JS timers do not fire while the view is closed.
- Delete only elements inside the current lasso: `deletePageElements` on anything outside it unbinds the note (error 105, note closes).
- Touch dp × `PixelRatio.get()` = page px.
- Keep every touch target inside its ancestors' bounds. A value row hanging under the strip (`position: absolute`, `overflow: visible` up to the strip) opened and closed unreliably on the device (GH-58); the row sits inside the strip now.
- The host's React pools synthetic events: read `e.nativeEvent` fields synchronously in the handler, never inside a state updater or after an `await` (GH-56: `nativeEvent` was null and the view closed without a message).
